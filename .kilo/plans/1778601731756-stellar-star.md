# Multi-Module Maven Project: React Web + Spring Boot Backend with User Login

## Overview
Create a multi-module Maven project with:
- **Parent project**: `myapp` (Java 21, Spring Boot 3.2.x)
- **Backend module**: Spring Boot REST API with H2 database and JWT authentication
- **Frontend module**: React app built with Vite with login UI

## Implementation Steps

### Step 1: Create Parent POM
- Create root `pom.xml` with:
  - Packaging: `pom`
  - Modules: `backend`, `frontend`
  - Parent: `spring-boot-starter-parent` 3.2.x
  - Properties: Java 21, project encoding
  - Dependency management

### Step 2: Create Backend Module
- Create `backend/pom.xml` with:
  - Parent: `myapp`
  - Dependencies:
    - `spring-boot-starter-web`
    - `spring-boot-starter-security`
    - `spring-boot-starter-data-jpa`
    - `spring-boot-starter-validation`
    - `jjwt-api`, `jjwt-impl`, `jjwt-jackson` (JWT library)
    - `h2` database
    - `spring-boot-starter-test`
  - Build plugins: spring-boot-maven-plugin

- Create application structure:
  - `BackendApplication.java` - Main Spring Boot class
  - `SecurityConfig.java` - Spring Security configuration with JWT filter
  - `JwtConfig.java` - JWT configuration properties
  - `AuthController.java` - Login/Register endpoints
  - `HealthController.java` - Simple REST endpoint for testing
  - `User.java` - JPA entity with username, password, roles
  - `UserRepository.java` - Spring Data JPA repository
  - `UserService.java` - User registration and authentication logic
  - `JwtService.java` - JWT token generation and validation
  - `JwtAuthenticationFilter.java` - JWT request filter
  - `JwtAuthenticationEntryPoint.java` - Unauthorized response handler
  - `application.yml` - H2 configuration, server port 8080, JWT settings

### Step 3: Create Frontend Module
- Create `frontend/pom.xml` with:
  - Parent: `myapp`
  - Plugin: `frontend-maven-plugin` to:
    - Install Node.js and npm
    - Run `npm install`
    - Run `npm run build`

- Create React + Vite structure:
  - `package.json` - React, Vite, axios, react-router-dom dependencies
  - `vite.config.js` - Vite configuration with proxy to backend
  - `index.html` - Entry HTML
  - `src/main.jsx` - React entry point with router
  - `src/App.jsx` - Main React component with protected routes
  - `src/App.css` - Basic styling
  - `src/api/auth.js` - API calls for login/register
  - `src/components/Login.jsx` - Login form component
  - `src/components/Login.css` - Login form styling
  - `src/context/AuthContext.jsx` - Authentication context for state management

### Step 4: Configure Integration
- Backend CORS configuration for frontend development
- Vite proxy configuration to forward API calls to backend
- Maven build order: frontend builds first, then backend

### Step 5: Add Build Scripts
- Root-level scripts for:
  - `mvn clean install` - Build all modules
  - `mvn spring-boot:run -pl backend` - Run backend
  - `npm run dev` in frontend - Run frontend dev server

## Authentication Flow

### Backend API Endpoints
- `POST /api/auth/register` - Register new user
  - Request: `{ username, password }`
  - Response: `{ message, token }`
- `POST /api/auth/login` - Login
  - Request: `{ username, password }`
  - Response: `{ token, username }`
- `GET /api/user/profile` - Get user profile (requires JWT token)
  - Header: `Authorization: Bearer <token>`
  - Response: `{ username, roles }`

### Frontend Authentication
- Login page with username/password form
- JWT token stored in localStorage
- AuthContext provides authentication state
- Protected routes redirect to login if not authenticated
- Axios interceptor adds JWT token to requests

## Testing Strategy
- Backend: Unit tests with Spring Boot Test, test authentication flow
- Frontend: Basic component renders, test login form
- Integration: Verify frontend can call backend API, login/logout flow

# Multi-Module Maven Project Plan

## Overview
Create a multi-module Maven project with:
- **Parent POM**: Manages dependencies, plugins, and Java version across modules
- **shared-lib**: Pure Java library module (reusable utilities)
- **app**: Spring Boot 3.4.x application module (depends on shared-lib)

**Configuration**: Package `me.ai-project`, Java 21, Spring Boot 3.4.x

---

## Project Structure

```
boulder-pineapple/
├── pom.xml                          # Parent POM
├── shared-lib/
│   ├── pom.xml
│   └── src/
│       ├── main/java/me/ai_project/shared/
│       │   └── StringUtil.java      # Example utility class
│       └── test/java/me/ai_project/shared/
│           └── StringUtilTest.java  # Example test
└── app/
    ├── pom.xml
    └── src/
        ├── main/java/me/ai_project/app/
        │   ├── AppApplication.java   # Spring Boot main class
        │   └── HelloController.java  # Example REST controller using shared-lib
        ├── main/resources/
        │   └── application.yml
        └── test/java/me/ai_project/app/
            └── AppApplicationTests.java
```

---

## Implementation Steps

### 1. Create Parent POM
- groupId: `me.ai-project`
- artifactId: `myproject-parent`
- packaging: `pom`
- Java 21 compiler configuration
- Declare `shared-lib` and `app` as modules
- Manage Spring Boot BOM via `spring-boot-dependencies`

### 2. Create shared-lib Module
- artifactId: `shared-lib`
- Pure Java library, no Spring dependencies
- Add example `StringUtil` class with a simple utility method
- Add JUnit 5 test dependency and example test

### 3. Create app Module
- artifactId: `app`
- Parent: `myproject-parent`
- Dependencies: `spring-boot-starter-web`, `shared-lib`
- Spring Boot Maven Plugin for packaging
- Example `HelloController` that uses `StringUtil` from shared-lib
- `application.yml` with basic config

### 4. Verify Build
- Run `mvn clean install` from parent directory
- Confirm both modules compile and tests pass

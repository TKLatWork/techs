概述

todos-service：管理和操作待办事项（Todo）的服务模块——新增、查询、列表（可按状态过滤）、修改、标记完成、删除。

形态：纯 Java（无框架依赖），本版本内存存储（进程级 Map，不持久化）；对外以 TodosService 接口为 Contract。

读者路径：实现者读「对外接口 / 契约」+「实现设计 / 架构」两 tab；测试读「测试」tab。

Terminology

术语定义
Todo一条待办事项：id、title、description、status、createdAt、updatedAt
title待办标题，非空（去首尾空白后长度 ≥ 1）
Status待办状态枚举：TODO（待办）｜DONE（已完成）
TodosService对外服务接口（Contract 主体），管理与操作 Todo
内存存储进程级 Map<String, Todo>，进程退出即失，无持久化

用户场景

#场景说明
S1新增待办给出标题（可选描述），得到带 id 的 Todo（status=TODO）
S2查看详情按 id 取单条 Todo
S3列表 / 过滤列出全部，或按 status 过滤（如只看 TODO）
S4修改待办按 id 更新 title / description
S5标记完成按 id 将 status 置为 DONE
S6删除待办按 id 删除

行为契约图示

操作输入输出副作用错误
addtitle（非空）、description（可空）新建 Todo（id 自动生成，status=TODO，createdAt=updatedAt=now）存储新增一条title 空 → E_INVALID_TITLE
getid对应 Todo无id 不存在 → E_NOT_FOUND
listfilter（可空：null=全部）Todo 列表（按 createdAt 升序）无—
updateid、title（非空）、description更新后的 Todo（updatedAt=now）存储更新E_NOT_FOUND / E_INVALID_TITLE
completeidstatus=DONE 的 Todo（updatedAt=now；已 DONE 时幂等返回）存储更新E_NOT_FOUND
deleteid无（void）存储删除一条E_NOT_FOUND
需求细则（边界与错误场景）
#边界行为
B1title 为 null / 空串 / 纯空白E_INVALID_TITLE（校验 = 去首尾空白后长度 ≥ 1）
B2id 不存在（get/update/complete/delete）E_NOT_FOUND
B3complete 已 DONE 的 Todo幂等：仍返回该 Todo（status=DONE），不报错
B4update 不修改 status状态流转仅由 complete 触发（本版本无「取消完成」操作）
B5list 结果为空返回空列表（非 null、不报错）

对外接口（TodosService · Interface）

public interface TodosService {
    Todo add(String title, String description);   // S1；E_INVALID_TITLE
    Todo get(String id);                          // S2；E_NOT_FOUND
    List<Todo> list(Status filter);               // S3；filter=null 返回全部，createdAt 升序
    Todo update(String id, String title, String description); // S4；E_NOT_FOUND / E_INVALID_TITLE
    Todo complete(String id);                     // S5；E_NOT_FOUND；已 DONE 幂等
    void delete(String id);                       // S6；E_NOT_FOUND
}

数据契约

Model：Todo

字段类型约束
idString服务端生成（UUID），全局唯一，不可变
titleString非空（去首尾空白后长度 ≥ 1）
descriptionString可空（null 允许）
statusStatusTODO ｜ DONE；新建固定 TODO；仅 complete 置 DONE
createdAtlong创建时刻 epoch millis，不可变
updatedAtlong最近修改时刻 epoch millis（add 时 = createdAt）

错误定义

错误载体触发
E_NOT_FOUNDTodoException extends RuntimeException，携带 TodoError 枚举id 不存在（get/update/complete/delete）
E_INVALID_TITLEtitle 为 null/空/纯空白（add/update）
public enum TodoError { E_NOT_FOUND, E_INVALID_TITLE }
public class TodoException extends RuntimeException {
    private final TodoError error;   // 错误码
    public TodoException(TodoError error, String message) { ... }
    public TodoError error() { return error; }
}
